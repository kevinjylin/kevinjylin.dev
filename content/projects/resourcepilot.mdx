Built with Kasey Doan at LA Hacks' AI Hackathon 2026, where it won 2nd place in the Fetch.ai Agentverse track.

The first few weeks at a new school are a pile of small questions: where can I study right now,
what's on this week, which dorm fits me? ResourcePilot answers them in one ASI:One chat.

- **Eight agents, one job each.** Each runs as its own process with its own address. The
  orchestrator hands every step to another agent and accepts only the result that matches the
  request it sent.
- **Works at any US school.** Your email domain is matched to the school in IPEDS, then the library's
  booking system is found from a hand-checked list, a LibCal probe or a bounded crawl. If none turns
  up, it asks you for the link instead of guessing.
- **Never makes anything up.** A verifier re-checks every room before you see it. If a room is taken
  mid-check, the planner reroutes to another open one; if live data fails, you get the school's own
  booking link, never invented rooms.
- **One paid step, checked by the seller.** The housing match is paid through Fetch's Agent Payment
  Protocol in Stripe test mode or testnet FET. The orchestrator verifies each payment itself and
  accepts each transaction ID only once.
